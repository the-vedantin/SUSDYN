# Rule 15 — Tie rods inline

## The rule
The tie-rod (or toe-link) ends line up laterally: "inline" means the same X, not
the same Y. The inner and outer tie-rod points should share their lateral
position sense, not be stacked fore-aft.

## Why
"Inline" here is about the steering/toe link running clean across the car. Reading
"inline" as the same Y (stacking the ends fore-aft at the same longitudinal
station) puts the link on the wrong axis and, in one case, ran the tie rod
through the ball joint. The correct reading is same X — the ends inline
laterally.

## History
- A layout that put the tie rod through the ball joint (reading "inline" as same
  Y) was rejected; "inline" was clarified to mean same X.
- On the rear, the lower A-arm and toe link are one fabricated welded part, so
  their mutual interference is exempt in the clash check (a designed joint, not a
  clash).

## How Vahan holds it
The tie-rod ends are wheel-locating points (see Rule 08) and are set by the
kinematic design; keep them inline in X. The clash check exempts the designed
rear A-arm-plus-toe-link joint.
